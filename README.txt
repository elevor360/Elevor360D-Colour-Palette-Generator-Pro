Elevor360D Colour Palette Generator Pro V1

Upload all files and folders to a new GitHub repository and enable GitHub Pages.
Advert images go in advertising/images/. Edit advertising/adverts.json to add ads. Image entries may be filenames within that folder.
Install from Chrome once GitHub Pages is live. Images are processed locally and not uploaded.
Palette extraction uses approximate colour quantisation, not AI. Animated GIFs use a single frame.
